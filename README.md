# Power Line Digital Twin

Small practice project: 3D digital twin of a 10 kV power line. It combines a LiDAR point cloud with a GIS layer (GeoJSON) and places 3D poles and wires in the right spots.

Built with TypeScript and [Three.js](https://threejs.org/).

## What it does

- Loads a LiDAR point cloud (`.xyz`, ~50k points) with classes: ground, vegetation, wire, pole
- Loads poles and spans from GeoJSON (lon/lat) and converts them to local meters
- Builds 3D poles, crossarms and wires with sag
- Puts each pole on the ground using the height of ground points around it
- **Snap to LiDAR**: finds the real pole in the scan near the GIS point and moves the 3D pole there. The table shows how far the GIS position was off (> 1.5 m is highlighted) and the real pole height
- Color points by class or by height, show/hide layers, 3D view and top view (2D map)

## Data

The data is generated by [`scripts/generate-data.ts`](scripts/generate-data.ts), not real. GIS positions have a 0.5–2.5 m error on purpose, to have something to fix.

```bash
node scripts/generate-data.ts
```

## Run locally

```bash
npm install
npm run dev
```
